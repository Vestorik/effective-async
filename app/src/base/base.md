Пакет app.src.base — Базовая инфраструктура приложения
Этот пакет предоставляет базовые компоненты для инициализации, конфигурации и жизненного цикла FastAPI-приложения. Он отвечает за сборку конфигурации из переменных окружения, настройку логирования, управление сессиями БД и регистрацию роутеров.

📂 Файлы пакета

1. config.py — Конфигурация и настройки
Централизованный модуль для управления всеми параметрами приложения с использованием pydantic-settings.

UvicornConfig: Параметры запуска сервера (хост, порт, воркеры, логирование, цикл событий).
PostgresDatabaseConfig: Параметры подключения к PostgreSQL (хост, порт, креды, пул соединений). Генерирует строку подключения (connection_url).
RedisConfig: Параметры подключения к Redis (хост, порт, SSL, пароль).
AuthConfig: Настройки JWT (секретный ключ, время жизни токенов).
Глобальные экземпляры:
uvicorn_config: Экземпляр конфигурации сервера.
MAIN_AUTH_CONFIG: Экземпляр конфигурации аутентификации.
_GLOBAL_DATABASE_MANAGER: ContextVar для безопасного доступа к менеджеру данных в асинхронном контексте.

Логирование: Настройка ConcurrentRotatingFileHandler для записи логов в файл.
2. lifespan.py — Управление жизненным циклом
Определяет события startup и shutdown для FastAPI приложения.

startapp(app):
Регистрирует API роутеры.
Настраивает тему Swagger UI.
Инициализирует DataManager (менеджер БД).
Регистрирует SQLAdmin панель администрирования.
Сохраняет DataManager в состояние приложения (app.state) и в глобальный ContextVar.

shutdown(app):
Корректно закрывает соединения с БД через DataManager.

lifespan(app):
Контекстный менеджер, оборачивающий старт и остановку в try-finally блок для гарантии очистки ресурсов.

1. main.py — Точка входа
Создает и экспортирует экземпляр FastAPI приложения.

create_app(): Фабричная функция для создания объекта FastAPI.
Настраивает метаданные (title, description, version).
Отключает стандартные docs (оставляет только Redoc).
Подключает lifespan хендлер.

MAIN_APP: Глобальный экземпляр приложения, экспортируемый для uvicorn.
main(): Функция для прямого запуска приложения из командной строки.
4. utils.py — Утилиты
Вспомогательные функции для валидации данных.

check_time_range(start_datetime, end_datetime, min_duration_minutes):
Проверяет, что end_datetime строго больше start_datetime.
Проверяет, что разница во времени не меньше min_duration_minutes.
Выбрасывает ValueError при нарушении условий.

🛠 Архитектурная роль
Пакет base является фундаментом, на котором строится остальное приложение:

Изоляция зависимостей: Конфигурация вынесена в отдельный файл, что позволяет легко менять параметры без изменения бизнес-логики.
Безопасность: Пароли и секреты не хранятся в коде, а загружаются из .env. Используется ContextVar для потокобезопасного доступа к общим ресурсам (БД).
Надежность: Внедрение lifespan гарантирует, что ресурсы БД освобождаются при остановке сервера. Логирование настроено на запись в файл с ротацией, чтобы не переполнять диск.
Масштабируемость: Конфигурация сервера (количество воркеров, таймауты) легко настраивается через переменные окружения.
⚙️ Пример использования
Python

# Импорт конфигурации

from app.src.base.config import uvicorn_config, MAIN_AUTH_CONFIG

# Использование в основном модуле (main.py)

import uvicorn
from app.src.base.main import MAIN_APP

if __name__ == "__main__":
    uvicorn.run(
        "app.src.base.main:MAIN_APP",
        host=uvicorn_config.host,
        port=uvicorn_config.port,
        log_level=uvicorn_config.log_level,
        workers=uvicorn_config.workers,
        loop=uvicorn_config.loop,
    )
